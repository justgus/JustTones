# EP-011 — iPhone Custom Tuning Profile Authoring

Status: active by explicit user direction on 2026-09-21. The user also explicitly authorized parallel activation with SP-020.

## Objective

Deliver the deferred iPhone authoring surface over the existing profile model and atomic local store. This corrects the presentation scope originally assigned to SP-010; it does not add Watch authoring, cloud synchronization, accounts, analytics, or network access.

## Known gaps at activation

The current UI supports creating a named-pitch profile, duplicate/reorder/delete, and persistence. It does not edit an existing pitch entry, hide or restore built-in templates, restore selected pitch/timbre state, or provide UI coverage for the lifecycle. Custom tuning-system authoring remains separately unimplemented under JT-FR-007 and is not represented as delivered here.

T-0031 remains Active until its accepted profile-authoring scope has deterministic UI/persistence evidence. Only the user may verify it.
