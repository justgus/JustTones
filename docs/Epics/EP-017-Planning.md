# EP-017 — Requirements Verification Run of Record

**Status:** Backlog

Run the final release evidence program only after the remaining delivery Epics are closed. It does not add product features.

**Scope:** turn the existing 241 test definitions into executed, reproducible records; close any missing test implementation; execute device/manual requirements; reconcile each of the 233 Active requirements to implementation and recorded evidence.

**Exit evidence:** every applicable requirement has implementation traceability, executed automated or manual evidence, and an explicit disposition. Release-only requirements then pass to EP-008.

**Dependency:** EP-012 through EP-016 complete; EP-008 remains the App Store/release-qualification Epic and is not superseded.
