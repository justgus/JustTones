**Rationale:**
The product must serve a multi-instrument musician without hard-coded instrument assumptions.

**Acceptance Criteria:**
1. The general profile model preserves stable identity, ordered entries, optional groups, repeated entries, transposition, preferred-timbre identifiers, and duplicate display names.
2. The platform-neutral library safely creates, replaces, duplicates, reorders, removes, and restores profiles with arbitrary practical entry counts; it does not start playback.
3. Versioned local persistence provides deterministic legacy migration, atomic autosave, last-valid snapshots, corrupt-store preservation and recovery, explicit reset, and backup-eligible caller-selected placement.
4. The foundation is local-only and has no account, cloud database, analytics, runtime network, microphone, iPhone authoring UI, catalog content, or Watch synchronization transport.
