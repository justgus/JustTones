# SP-035 — Predefined Tuning-System Discovery

**Epic:** EP-014 · **Task:** T-0045 · **Status:** Planning; not activated

Expose the existing eight version-one systems as read-only predefined entries, distinct from user-owned systems. Provide useful search and filters, detail views, available provenance and limitation disclosures, accessible/localized labels, and clear empty states. Browse, selection, and return remain silent.

**Acceptance:** catalog identity and immutability are preserved; search/filter and no-result behavior is deterministic; the current catalog's provenance is communicated without implying unsupported cultural coverage.

**Verification:** catalog data/manifest inspection, filtering and search tests, catalog UI coverage, and accessibility/localization inspection.

No implementation is authorized by this plan.
