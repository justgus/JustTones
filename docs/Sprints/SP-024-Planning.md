# SP-024 — Apple Watch Interaction Adaptation

**Status:** Active. T-0034 is implemented and awaiting user verification.

**Goal:** derive a safe, constrained Watch interaction model from the approved iPhone model.

**Scope:** define compact/expanded/unavailable/disconnected states; retain essential profile, pitch, frequency, actual playback, transport, timbre, and output-level operation; specify focused Digital Crown semantics; record the iPhone-only administration boundary.

**Acceptance target:** JT-AC-050, inspected by Draft test JT-TEST-244.

**Dependency:** satisfied — SP-022 and SP-023 outputs are verified.

**Out of scope:** watchOS code, Watch profile authoring, remote control of iPhone audio, and device qualification.
