# SP-036 — Profile Creation and Tuning Workflows

**Epic:** EP-014 · **Task:** T-0046 · **Status:** Planning; not activated

Allow a musician to create or duplicate an editable profile from a selected predefined system. Preserve the profile's reference configuration, disclose mismatches, and support grouping plus written/sounding pitch presentation without changing resolved frequency or starting playback.

**Acceptance:** source catalog entries remain immutable; created profiles persist after reload; reference disclosure is truthful; grouping and pitch labels preserve entry identity and sound.

**Verification:** create/duplicate, persistence, reference mismatch, grouping, written/sounding, and silent-selection coverage on iPhone and Watch.

No implementation is authorized by this plan.
